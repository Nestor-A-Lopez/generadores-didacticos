The action control for everything a learner can do — start a lesson, check an answer, continue.

```jsx
<Button variant="primary" size="lg" iconRight="arrow-right">Empezar la lección</Button>
```

One `primary` per view. `secondary` for the soft blue companion action, `outline` on white photography/illustration grounds, `ghost` inside toolbars and cards, `inverse` on deep-blue sections. Labels are sentence case, verb-first, and never shouty ("Revisar respuesta", not "REVISAR").
