# Mazo de diapositivas — Vesta

Siete tipos de diapositiva a 1280×720. Cada archivo es autónomo: enlaza `../styles.css` y usa sólo estilos en línea.

| Tipo | Archivo | Cuándo |
| --- | --- | --- |
| Portada | `TitleSlide.html` | Apertura. Motivo de capas a la derecha, título display a 86px. |
| Separador | `SectionSlide.html` | Cambio de bloque. Azul profundo a sangre, número de sección. |
| Concepto | `ConceptSlide.html` | Una idea en tres pasos numerados. |
| Fórmula | `FormulaSlide.html` | La ecuación como protagonista, con las variables nombradas en palabras. |
| Comparación | `ComparisonSlide.html` | Dos enfoques enfrentados; el nuestro siempre en la tarjeta azul. |
| Datos | `DataSlide.html` | Tres cifras como máximo, cada una con su frase. |
| Cita | `QuoteSlide.html` | Fraunces itálica, sin comillas decorativas más allá de las angulares. |
| Cierre | `ClosingSlide.html` | Una frase y el siguiente paso. |

## Mazo de clase (repaso · objetivos · ejercicios)

Set adicional pensado para sesiones de clase, con la misma distribución que un mazo de conferencia clásico (título arriba a la izquierda, línea + marca de agua al pie) pero en la paleta azul de Vesta:

| Tipo | Archivo(s) |
| --- | --- |
| Título de clase | \`ClassTitleSlide.html\` |
| Repaso | \`RecapSlide.html\` |
| Objetivos | \`ObjectivesSlide.html\` |
| Título de sección (3 opciones) | \`SectionTitleGhost.html\` · \`SectionTitleDeep.html\` · \`SectionTitleSplit.html\` |
| Ejemplos (3 opciones) | \`ExampleSingle.html\` · \`ExampleComparison.html\` · \`ExampleTriple.html\` |
| Conclusiones (3 opciones) | \`ConclusionsList.html\` · \`ConclusionsStatement.html\` · \`ConclusionsData.html\` |
| Ejercicios (3 opciones) | \`ExerciseOpen.html\` · \`ExerciseChoice.html\` · \`ExerciseSteps.html\` |

**Reglas del mazo:** como mucho dos fondos por presentación (blanco y azul profundo); el azul hundido `--surface-sunken` sólo para diapositivas de datos o fórmulas. Ningún texto por debajo de 19px. Las fórmulas siempre en la familia matemática, nunca en Poppins.
